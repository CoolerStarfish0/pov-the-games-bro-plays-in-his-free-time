# In His Free Time

A chaotic little browser arcade made with plain HTML, CSS, and JavaScript.

## Games
- **The WiFi Final Boss** — deliver as many packets as possible before time runs out.
- **Escape the Group Project** — finish the whole project yourself.
- **NPC Teacher Simulator** — react when the teacher is looking away.
- **The Last Chair** — wait for the right moment to claim the seat.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The site will publish at the repository's GitHub Pages URL.
